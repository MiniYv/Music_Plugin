# 小禹听歌插件

QQ音乐搜索与点歌，支持歌名搜索、选择歌曲、查看详情与播放链接，搜索结果以精美图片展示。

## 命令

| 命令 | 说明 |
|---|---|
| /点歌 <歌名> | 搜索 QQ 音乐歌曲（例：/点歌 周深）|
| /qq音乐 | 同 /点歌，搜索 QQ 音乐 |
| /选择 <序号> | 从上一次搜索结果中选择歌曲 |
| /歌曲详情 | 查看上一首选中歌曲的详情 |
| /清理缓存 | 清理超过指定天数的缓存文件（默认 7 天）|

## 使用示例

```
/点歌 周深
→ 返回搜索结果图片，每首歌带序号
/选择 1
→ 获取第 1 首歌的播放链接与详情
```

## 安装

```bash
loyan plugins install MiniYv/Music_Plugin
```
